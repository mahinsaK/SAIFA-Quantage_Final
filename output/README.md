# Generated output

This directory contains reproducible artifacts generated by the command
scripts, including prepared data, portfolio results, risk analyses, backtests,
stress analyses, the annual portfolio experiment, and the Streamlit data bundle.

Each generated run contains `status.json`, `summary.json` where applicable,
and a deterministic `manifest.json` listing and hashing the files in that run.
The Streamlit bundle has its own `bundle.json` manifest covering all stages.

The generated files are intentionally ignored by Git because they can be
recreated from the tracked frozen input snapshot under `data/snapshots/`.
From a fresh clone, use the [root README quick start](../README.md#start-here-run-the-app-from-a-fresh-clone)
to prepare the app, committee evidence, annual experiment and PDFs with one command:

```bash
uv run --locked python commands/run_judge_app.py
```

`commands/run_app_data.py` prepares only the app data bundle; it does not
create the final PDFs. Include the generated PDFs in the actual submission
package, since Git tracks the frozen inputs and source code but not `output/`.

`adaptive/<snapshot-id>/` is the separately verified annual-refitting experiment.
It retains its own targets, comparison periods, source hashes and pending review.
It does not replace the frozen-candidate risk or submission evidence.
